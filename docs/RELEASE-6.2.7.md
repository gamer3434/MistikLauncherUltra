# Mistik Launcher Ultra 6.2.7

Online ve offline kuruculara **Mevcut kurulumu onar** seçeneği eklendi. Seçip kurulum klasörünü belirtin ve **Onar** düğmesine basın. Launcher önce kapatılmalıdır. Eksik veya bozuk program dosyaları doğrulanmış kopyalarıyla yenilenir; ayarlar, modlar, dünyalar ve kullanıcı dosyaları korunur. Online kurucuda internet gerekir; offline kurucu paketini kullanır. Ayrı onarıcı EXE de kullanılabilir.

Online and offline installers now include **Repair existing installation**. Select it, choose the installation folder and press **Repair** after closing the launcher. Verified files replace missing or damaged application files while preserving settings, mods, worlds and user files. The online installer requires internet; the offline installer uses its embedded package. The standalone repair EXE remains available.
