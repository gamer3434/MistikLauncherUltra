# Mistik Launcher 6.2.0

## Türkçe

- Normal sürüm, kod gizleme olmadan derlenir. Taşınabilir ZIP, online/offline kurulum ve bağımsız onarıcı birlikte sunulur.
- Ana panelde büyük dekoratif alanlar kaldırıldı. Hızlı işlemler küçük pencerede de görünür; oyun durumu, seçili sürüm ve başlat düğmesi korunur.
- Oyuncu adı, RAM, dil ve giriş yöntemi ayarların ilk bölümüne taşındı. 20 tema, 16 pencere stili ve menü seçenekleri açılır görünüm bölümündedir. Mevcut tercihler korunur.
- Sürüm yöneticisi başlığı ve yenileme düğmesi Türkçe/English seçimine uyar. Eski önizleme kurulum mesajları düzeltildi.
- Ana paneldeki sürüm bilgisi, seçim hangi sayfadan yapılırsa yapılsın güncellenir.
- Oyun onarımında hedef klasör oluşturulamıyorsa dosya ve hata bilgisi gösterilir; mevcut dosyalar korunur.
- **MistikRepair-6.2.0.exe** internet gerektirmeden eksik/bozuk program dosyalarını doğrular ve yeniler. Launcher'ı kapatın, kurulum klasörünü kontrol edip **Onar** seçin. Ayarlar, modlar ve dünyalar korunur.

## English

- Regular build without obfuscation, with a portable ZIP, online/offline installers and a standalone repair tool.
- Compact home page keeps quick actions visible at the minimum window size. Game readiness and the launch controls remain available.
- Player name, RAM, language and authentication settings come first. All 20 themes, 16 caption styles and navigation options remain in the expandable appearance section; existing preferences are preserved.
- Localized version manager heading and refresh button; corrected obsolete preview installation messages.
- Home profile information refreshes when the selected version changes through any page.
- Failed runtime repair directory creation reports the affected artifact without replacing existing files.
- Close the launcher and use **MistikRepair-6.2.0.exe** to repair program files offline. Settings, mods and worlds are preserved.
