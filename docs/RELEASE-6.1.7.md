# Mistik Launcher Ultra 6.1.7

## Türkçe

- Sürümler sayfasında filtre değiştirildiğinde seçili düğmenin vurgusu güncellenir; gösterilen listeyle seçili filtre eşleşir.
- Seçili oyun profili başka bir menüden değiştirildiğinde Sürümler sayfasındaki kartlar güncellenir; önbellekteki sayfa yeniden açılınca son seçimi gösterir.
- Arkadaşlar sayfası yeniden açıldığında etkin tünelin durumunu gösterir; eski veya kapalı sayfaya ait tünel bildirimleri mevcut düğmeleri değiştirmez.
- Güncelleme paketi doğrulaması ve yardımcı dosya kopyalama arka planda yapılır. Kurulum başlamadan launcher'ın boşta olduğu tekrar denetlenir; aynı güncelleme için birden fazla kurulum başlatılmaz.

## English

- The selected filter button on the Versions page now updates when the filter changes, matching the displayed list.
- Version cards update when the selected game profile changes in another menu. Reopening the cached page shows the latest selection.
- Reopening the Friends page restores the active tunnel status. Stale tunnel notifications from a closed page no longer change the current controls.
- Update payload verification and helper copying run in the background. Launcher idle state is checked again before installation, and duplicate installer launches are blocked.
