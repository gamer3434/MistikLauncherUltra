## Türkçe

- Dil değiştirirken mod ayrıntıları artık açıklamaya dönmez. Açık sekme, açıklama tarayıcısı, sürüm listesi ve galeri korunur.
- Dil değişimi mod bilgilerini yeniden indirmez. Hazır içerik çevrimdışıyken de kullanılabilir; bekleyen istek iptal edilmez veya çoğaltılmaz.
- Başarısız mod yüklemesinden sonra “Tekrar dene” önceki seçili sekmeyi geri açar.
- Galerideki yükleme, hata ve yeniden deneme yazıları mevcut içerik korunarak çevrilir.

783 normal ve 795 paket kontrolü geçti. Çevrimdışı yanıtlar, geciktirilmiş istekler, içerik kimliği, dil değişimi ve yeniden deneme geçici test verileriyle doğrulandı. Gerçek Minecraft oturumu denenmedi.

## English

- Changing language no longer returns mod details to Description. The selected tab, description browser, version list and gallery are preserved.
- Language changes do not fetch project metadata again. Loaded content remains available offline, and pending requests are neither cancelled nor duplicated.
- Retrying a failed project load restores the previously selected tab.
- Gallery loading, failure and retry labels translate without replacing existing content.

783 ordinary and 795 packaged checks passed. Offline responses, delayed requests, content identity, language changes and retry were verified with temporary test data. A real Minecraft session was not tested.
