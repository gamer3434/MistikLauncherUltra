# Mistik Launcher Ultra 6.1.5

## Türkçe

- Mistik Launcher hesabı, kayıt/giriş ekranları ve bulut ayar yedeği kaldırıldı. Eski hesap sayfası ana sayfaya yönlendirilir; bulut profil erişimi kapatıldı.
- Üst menüye **Güncellemeler** sayfası eklendi. Mevcut sürüm, otomatik güncelleme seçeneği, sürüm denetimi, indirme ilerlemesi ve resmî sürüm notları burada gösterilir.
- Ayarlar sayfasındaki güncelleme denetimi de kullanılabilir; iki sayfa aynı güncelleme durumunu gösterir.

## English

- Removed Mistik Launcher accounts, registration/sign-in screens and cloud preference backup. The old account URL redirects to the homepage; cloud profile access is closed.
- Added a dedicated **Updates** page to the top menu. It shows the current version, automatic update option, update check, download progress and official release notes.
- The update controls remain available in Settings; both pages show the same updater state.
