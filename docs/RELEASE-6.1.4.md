# Mistik Launcher Ultra 6.1.4

## Türkçe

- Launcher'da kayıt tamamlandığında doğrulama e-postası, hesap durumunu yeniden sorgulamadan gönderilir. E-postadaki bağlantı açıldıktan sonra giriş yapılabilir.
- Oturum kapatılırken kayıtlı giriş dosyası silinemese bile etkin oturum hemen kapanır. Bu durumda launcher, yeniden açılmadan önce silinmesi gereken dosyayı bildirir.
- Web hesabında dil seçimi sayfa değiştirildiğinde korunur. İndirme ve sürüm bağlantıları güncel kararlı yayınla eşleşir.

## English

- Launcher registration sends the verification email without a separate account status lookup. Sign in after opening the link in the email.
- Signing out clears the active session even if the saved sign-in file cannot be removed. In that case, the launcher identifies the file to remove before reopening.
- The website keeps the selected language across pages. Download and version links follow the latest stable release.
