# Bulut profilleri / Cloud profiles

**Türkçe:** Bulut hesabı ve otomatik profil eşitlemesi, kullanıcı isteğiyle başlatıcıdan kaldırıldı. Güncel sürüm ayarları Windows kullanıcı hesabına bağlı şifreli yerel dosyada saklar. Eski Firebase hesapları ve uzaktaki profiller bu değişiklikle silinmez; bunları yönetmek için Firebase projesinin sahibi kendi konsolunu kullanmalıdır. Skin PNG doğrulaması yerel olarak çalışmaya devam eder.

**English:** Cloud account sign-in and automatic profile sync were removed from the launcher at the user's request. The current version stores settings in an encrypted local file bound to the Windows user account. Existing Firebase accounts and remote profiles are not deleted by this change; the project owner must manage them in the Firebase console. Local PNG skin validation remains available.
