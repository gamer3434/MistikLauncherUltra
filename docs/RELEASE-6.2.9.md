## Türkçe

- Ayarlar bölümünden HUD açılıp kapatılabilir; değişiklikten sonra Minecraft yeniden başlatılmalıdır. HUD dünyada görünür, ana menüde görünmez.
- Fabric 1.21.1 için FPS, koordinat, ping, WASD/CPS ve zırh göstergesi kurulumu eklendi. Kişisel HUD profilleri korunur.
- Shader merkezi, Iris/Sodium kurulumu ve doğrulanmış Modrinth shader indirmeleri eklendi.
- Minecraft 1.21/1.21.1 için MISTIK menü kaynak paketi eklendi; kişisel kaynak paketleri ve oyun ayarları korunur.
- CurseForge araması ve API anahtarı alanı kaldırıldı. Mod merkezi Modrinth kullanır.
- Mod kaynaklı bağlantı hataları daha doğru teşhis edilir; küçük pencerelerde mod araması görünür kalır.

## English

- Added an in-game HUD enable/disable switch in Settings. Restart Minecraft after changing it. HUD overlays appear in a world, not on the main menu.
- Added Fabric 1.21.1 HUD presets for FPS, coordinates, ping, keystrokes/CPS and armor, preserving personal profiles.
- Added shader browsing, Iris/Sodium installation and verified Modrinth downloads.
- Added MISTIK menu branding for Minecraft 1.21/1.21.1 while preserving existing packs and options.
- Removed CurseForge search and API key settings; the mod center uses Modrinth.
- Improved mod linkage crash diagnosis and compact window search layout.
