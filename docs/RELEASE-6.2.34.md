## Türkçe

- Mod kurulumundaki profil eşitleme, dosya doğrulama ve yazma işlemleri arka planda çalışır; büyük dosyaların arayüzü dondurmasına yol açan işler azaltıldı.
- Oyun açılırken veya çalışırken mod kurulumu, içe aktarma, geri yükleme, temizleme ve açma/kapatma işlemleri mod dosyalarını değiştiremez.
- Dil tercihi kaydedilemezse önceki dil ve seçim korunur; hata durum çubuğunda gösterilir.
- Kurulu modların dosya boyutları koyu zeminde daha okunur.
- Web panelinde eksik veya tekrarlanan yayın dosyaları yanlış indirme toplamı oluşturmuyor; dar ekranlarda filtre özeti satıra bölünüyor. Yeni sürümün notları eksikse eski sürümün duyuruları gösterilmiyor.

726 normal, 738 paket kontrolü ve 33 web testi geçti. Kontroller geçici dosyalar ve örnek verilerle çalışır; gerçek kullanıcı modları veya paylaşım tercihleri değiştirilmedi. Oyun içi oynanış ve tüm donanım kombinasyonları denenmedi.

## English

- Profile synchronization, file verification and writes during mod installation run in the background, reducing work that could freeze the interface for large files.
- Mod installation, imports, restores, cleanup and toggles cannot change mod files while Minecraft is starting or running.
- Failed language preference saves preserve the previous language and selection and show an error in the status bar.
- Installed mod file sizes are easier to read on dark cards.
- The web dashboard rejects incomplete or duplicate release asset totals and wraps long filter summaries. Missing release notes no longer display announcements from an older version.

726 ordinary checks, 738 packaged checks and 33 web tests passed using temporary files and fixtures. Real user mods and sharing preferences were not changed. Gameplay and every hardware combination were not tested.
