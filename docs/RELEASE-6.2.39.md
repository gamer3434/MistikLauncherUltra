## Türkçe

- Backspace’in gizli sayfa geçmişini çalıştırarak yanlış menüye götürmesi düzeltildi. Geri/ileri geçmişi menü seçimini atlayamaz; metin alanlarında silme ve açık menü düğmeleri çalışır.
- Admin paneline ayrı izinle paylaşan kurulumların oyuncu adı, son etkinliği, launcher sürümü, seçili profili ve gerçek mod dosyaları eklendi. İsme tıklayarak ayrıntılar açılır. Mod paketi adı dosyalardan tahmin edilmez.
- Panelden Modrinth modu arayıp seçili profile kurulum önerisi gönderilebilir. Alıcının hem destek paylaşımını hem önerileri açması ve gelen isteği launcher’da onaylaması gerekir. İndirme ve bağımlılıklar mevcut doğrulanmış kurulum yolunu kullanır.
- İstekler tek bekleyen kayıtla sınırlıdır. Süre, profil, proje türü, tekrar gönderim ve eşzamanlı değişiklikler denetlenir. Paylaşımı kapatma veya launcher’ı kapatma devam eden destek işlemini iptal eder.
- Normal anonim istatistik izni değişmez. Yeni isim/mod paylaşımı ve öneriler varsayılan kapalıdır. İlk 300 mod dosyası gösterilir; toplam ve sınır ayrıca belirtilir. İsimler kullanıcı beyanıdır; Minecraft hesabı doğrulaması değildir.

805 normal ve 817 paket kontrolü, 46 web testi, 102 yeni destek erişim kuralı kontrolü ve mevcut metrik emülatör testleri geçti. 360/768/1440 pikselde sentetik kullanıcılarla tarayıcı kontrolleri yapıldı. Gerçek kullanıcıya uzaktan mod kurulmadı; Minecraft oturumu denenmedi.

## English

- Fixed Backspace traversing hidden page history and opening the wrong launcher menu. Back/forward history cannot bypass menu selection; text deletion and explicit menu buttons still work.
- The private admin panel shows separately opted-in installation names, activity, launcher versions, selected profiles and actual mod filenames. Click a name for details. Modpack identities are not inferred from files.
- Administrators can search Modrinth and suggest a mod for a selected profile. Recipients must enable support sharing and suggestions, then approve each request in the launcher. Downloads and dependencies use the existing verified installer.
- Each installation has one pending request. Age, profile, project type, replay and concurrent changes are checked. Opt-out and shutdown cancel ongoing support work.
- Normal anonymous analytics consent is unchanged. Named support sharing and suggestions default to off. Inventories display the first 300 filenames with the true count and limit. Player names are self-reported, not verified Minecraft identities.

805 ordinary and 817 packaged checks, 46 web tests, 102 new support rule checks and the existing metrics emulator tests passed. Browser checks used synthetic installations at 360/768/1440 pixels. No remote mod was installed for a real user; a Minecraft session was not tested.
