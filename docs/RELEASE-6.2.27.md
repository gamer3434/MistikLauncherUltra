## Türkçe

- Dar pencerelerde kurulu modların yedekleme, geri yükleme ve temizleme düğmeleri taşmadan kullanılabilir.
- Boş veya 128 MiB üzerindeki yerel JAR dosyaları hedef klasör oluşturulmadan reddedilir; kopyalama sırasında kaynak dosya değiştirilemez. Hata mesajı boyut sınırını açıklar.
- Auto-MCS arayüz bildiriminde hata oluşması, başarıyla kurulan dosyaları başarısız gibi göstermez ve diğer bildirimleri engellemez.
- Mod kaldırma onayı, dosyanın yedeğe taşındığını doğru şekilde belirtir.
- GitHub özeti kısaltıldı; indirme bağlantısı, önemli özellikler ve güncel arayüz görselleri öne çıkarıldı.

Microsoft hesabıyla giriş henüz desteklenmez. Gerçek oyun içi oynanış ve fiziksel ekranlar arasında DPI geçişi bu turda ayrıca test edilmedi.

## English

- Installed mod backup, restore and cleanup controls fit compact windows without overflowing.
- Empty or oversized local JAR files are rejected before creating the destination; source files remain protected during copying. The error explains the 128 MiB limit.
- Auto-MCS notification errors no longer misreport committed updates or prevent other observers from running.
- Mod removal confirmations correctly describe moving files to a backup.
- The GitHub overview is shorter and highlights downloads, key features and current interface screenshots.

Microsoft account authentication is not yet supported. Actual Minecraft gameplay and physical mixed-DPI display transitions were not tested separately in this round.
