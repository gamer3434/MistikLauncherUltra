# Mistik Launcher Ultra 6.2.12

Fabric 1.21.1 oyun açılışında Mistik HUD nedeniyle oluşan çökme düzeltildi. HUD ayarları ve yerleşimleri korunur.

Hata raporları artık ölümcül Mixin hatasını, öncesindeki isteğe bağlı sınıf uyarısından ayırır.

HUD'u güncellemek için Modlar bölümündeki HUD kurulum düğmesini kullanın, ardından Minecraft'ı yeniden başlatın. Sağ Shift ile HUD düzenleyicisini açabilirsiniz.
