# Mistik Launcher Ultra 6.1.2

## Türkçe

- Web sitesinde e-posta ve parola ile Mıstık Launcher hesabı oluşturabilir, giriş yapabilir, e-posta adresini doğrulayabilir ve parola sıfırlama bağlantısı isteyebilirsin.
- Web hesabınla masaüstü launcher'ın **Hesap** bölümünde de giriş yapabilir veya hesap oluşturabilirsin. Bu Mıstık Launcher hesabı, Minecraft ya da Ely.by oyun hesabından ayrıdır; oyun giriş bilgileri ve parolalar eşitlenmez.
- Oturum açtıktan sonra **Ayarları hesaba yedekle** düğmesi isteğe bağlı bir yedekleme başlatır. Yalnızca oyuncu adı, oyun sürümü, RAM, arayüz dili ve tema yedeklenir. Parola, Minecraft/Ely.by kimlik bilgileri, modlar, skinler ve dünyalar gönderilmez.
- Yedekleme otomatik eşitleme değildir; launcher bu yedeği geri yüklemez. Ayarların yerel kopyası cihazda kalır.

## English

- Create a Mistik Launcher account on the website with an email and password, sign in, verify the email address, or request a password-reset link.
- Sign in to the desktop launcher's **Account** page with the same website account, or create an account there. This Mistik Launcher account is separate from Minecraft and Ely.by game accounts; game credentials and passwords are not synced.
- After signing in, **Back up settings to account** starts an optional backup. It includes only player name, game version, RAM, interface language, and theme. Passwords, Minecraft/Ely.by credentials, mods, skins, and worlds are not sent.
- This is not automatic synchronization, and the launcher does not restore the backup. The local settings copy remains on the device.
